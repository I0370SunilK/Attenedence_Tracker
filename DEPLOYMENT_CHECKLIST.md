# ============================================\n# SRM Attendance Tracker - Production Deployment Checklist\n# ============================================\n\n## Pre-Deployment Verification\n\n### Frontend\n- [ ] `frontend/.env` configured (or will use default)\n- [ ] `npm run build` completes without errors\n- [ ] No console errors in production build\n- [ ] API calls use relative URLs (`/api/*`)\n- [ ] Environment variables properly injected\n\n### Backend  \n- [ ] `backend/src/main/resources/application.properties` configured\n- [ ] Firebase `serviceAccountKey.json` present\n- [ ] `mvn clean package -DskipTests` completes successfully\n- [ ] No critical vulnerabilities in dependencies\n- [ ] Database migrations ready (if applicable)\n\n### Docker\n- [ ] `Dockerfile` multi-stage build optimized\n- [ ] `.dockerignore` excludes unnecessary files\n- [ ] `docker-compose.yml` for local testing\n- [ ] `start.sh` is executable and error-free\n- [ ] `nginx.conf` configured for API proxying\n\n### Render Configuration\n- [ ] `render.yaml` Blueprint file ready\n- [ ] Firebase credentials prepared (as environment variables)\n- [ ] Port configuration correct (8080)\n- [ ] Healthcheck endpoint configured\n\n---\n\n## Local Testing Before Deployment\n\n### Build Docker Image\n```bash\ndocker-compose build\n```\n\n### Run Container Locally\n```bash\ndocker-compose up\n```\n\n### Verify Services\n```bash\n# Test frontend\ncurl http://localhost:8080/\n\n# Test backend health\ncurl http://localhost:8080/health\n\n# Test API proxy\ncurl http://localhost:8080/api/auth/me\n\n# Check logs\ndocker-compose logs app\n```\n\n### Performance Testing\n```bash\n# Load testing (example)\nab -n 100 -c 10 http://localhost:8080/\n```\n\n---\n\n## Render Deployment Steps\n\n### 1. GitHub Preparation\n```bash\ngit add .\ngit commit -m \"Production Docker configuration\"\ngit push origin main\n```\n\n### 2. Create Render Blueprint\n1. Go to https://dashboard.render.com\n2. Click **\"New +\"** → **\"Blueprint\"**\n3. Select your GitHub repository\n4. Select the branch (usually `main`)\n5. Click **\"Connect\"**\n\n### 3. Configure Environment Variables\nRender will prompt for these variables (from `render.yaml`):\n\n**Required:**\n- `FIREBASE_SERVICE_ACCOUNT_JSON` - Your Firebase service account JSON\n- `FIREBASE_WEB_API_KEY` - Your Firebase Web API key\n\n**Optional:**\n- `ADMIN_EMPLOYEE_ID` - Admin username (default: Admin323)\n- `ADMIN_PASSWORD` - Admin password (default: from application.properties)\n- `ADMIN_RECOVERY_EMAIL` - Recovery email\n\n### 4. Deploy\nClick **\"Apply\"** and wait for build completion (typically 5-10 minutes)\n\n---\n\n## Post-Deployment Verification\n\n### Check Deployment Status\n```bash\n# View logs\nrender logs <service-name>\n\n# Check service health\ncurl https://<your-domain>/health\n```\n\n### Test Application\n1. Open https://<your-domain>/login\n2. Open DevTools → Network tab\n3. Attempt login with test credentials\n4. Verify API calls to `/api/auth/login` return 200 (not 404)\n5. Check response JSON contains user data\n\n### Monitor Performance\n- Render Dashboard → View logs and metrics\n- Check CPU/Memory usage\n- Monitor error rates\n- Check load times\n\n---\n\n## Common Issues & Fixes\n\n### Issue: 502 Bad Gateway\n**Cause**: Spring Boot not ready when Nginx proxies requests\n\n**Fix**:\n- Increase `MAX_RETRIES` in `start.sh`\n- Check backend logs: `render logs`\n- Verify Firebase credentials are set\n\n### Issue: 404 on /api endpoints\n**Cause**: Nginx proxy not configured or backend not running\n\n**Fix**:\n- Verify `nginx.conf` has `/api/` proxy block\n- Check backend is listening on port 8081\n- Verify API calls use relative URLs\n\n### Issue: Static assets not loading\n**Cause**: Frontend dist files not copied to Nginx\n\n**Fix**:\n- Verify Dockerfile Stage 1 builds successfully\n- Check `dist/` directory exists\n- Verify `COPY --from=frontend-builder /app/dist` in Dockerfile\n\n### Issue: Slow build times\n**Solution**:\n- Optimize Docker layer caching in Dockerfile\n- Use `.dockerignore` to exclude unnecessary files\n- Consider upgrading Render plan\n\n---\n\n## Performance Optimization\n\n### Dockerfile\n- ✅ Multi-stage build minimizes final image size\n- ✅ Dependencies cached in separate layer\n- ✅ Production builds skip tests\n\n### Nginx\n- ✅ Gzip compression enabled\n- ✅ Long-term caching for static assets (1 year)\n- ✅ Upstream backend configuration for load balancing\n- ✅ Connection pooling with keepalive\n\n### Spring Boot\n- ✅ Headless JRE (smaller than full JDK)\n- ✅ JVM memory tuning: `-Xmx512m -Xms256m`\n- ✅ Production profile active\n- ✅ Health checks configured\n\n---\n\n## Security Checklist\n\n- [ ] Firebase credentials stored as environment variables (NOT in code)\n- [ ] HTTPS enforced (Render
